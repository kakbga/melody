# JustMusic

一个可以直接部署在 GitHub Pages 上的在线音乐播放器。界面参考 Apple Music 的克制、留白与大封面，播放、歌词、收藏、歌单全部在浏览器本地完成，不需要服务器、不需要登录，也没有构建步骤。

![JustMusic 桌面端](assets/img/preview.jpg)


## 功能

- **搜索**：酷我音乐、网易云、QQ 音乐，以及 KMusic / lx-music 音源脚本提供的扩展音源
- **加载更多**：网易云、QQ 音乐的搜索结果每次追加 20 首，直到没有更多；酷我公开接口单次最多 10 首，不显示该按钮
- **网易云 / QQ 原生播放**：搜索结果直接播放对应平台的音频；VIP、付费或解析失败时，自动按歌名与歌手匹配酷我 320K 兜底
- **扩展音源**：设置里启用的脚本会合并成一个「扩展音源」页签，单个脚本失效时自动跳过，不会堆一排报错的音源
- **发现首页**：每日精选、华语流行、周杰伦经典、深夜低语、欧美精选、粤语金曲、专注时刻
- **完整播放器**：播放 / 暂停、上一首 / 下一首、随机、单曲循环、列表循环、音量、进度拖动
- **全屏播放页**：大封面、沉浸式模糊背景、逐行滚动歌词、点击歌词跳转
- **播放队列**：查看接下来、移除歌曲、直接切歌
- **收藏与最近播放**：保存在浏览器本地，随时找回
- **自建歌单**：新建、重命名、删除、添加歌曲、从歌单移除
- **音质切换**：标准 128K / 高品质 320K / 无损 FLAC，缺少无损版本时自动降级
- **深浅色外观**：深色、浅色、跟随系统
- **移动端适配**：侧边栏抽屉、底部播放条、全屏播放页
- **系统媒体控制**：支持 macOS / Windows 的媒体键与系统「正在播放」

## 直接运行

不部署也可以本地预览。因为浏览器对 `file://` 下的脚本加载有限制，建议起一个静态服务器：

```bash
cd justmusic
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个仓库，例如 `justmusic`。
2. 把本项目**根目录下的所有文件**上传到仓库（`index.html` 必须在仓库根目录，不要多套一层文件夹）。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 里选择 **Deploy from a branch**。
5. Branch 选 `main`，目录选 `/ (root)`，点击 **Save**。
6. 等待一两分钟，访问 `https://<你的用户名>.github.io/justmusic/`。

如果仓库名是 `<你的用户名>.github.io`，访问地址就是 `https://<你的用户名>.github.io/`。

项目已经包含 `.nojekyll`，GitHub Pages 不会再用 Jekyll 处理文件。以后更新只需要把新文件提交到 `main` 分支，Pages 会自动重新发布。

### 使用自定义域名

在 **Settings → Pages → Custom domain** 填入域名，并按 GitHub 的提示配置 DNS。GitHub 会在仓库里生成 `CNAME` 文件，不要删除它。

## 音源说明

项目里有三层音源，按优先级依次尝试：

| 层 | 用途 | 说明 |
| --- | --- | --- |
| 内置接口 | 搜索、播放、歌词 | 酷我公开接口 + 网易云 / QQ 搜索与直链解析，浏览器直接请求，无需配置 |
| lx 脚本宿主 | 扩展音源 | `assets/js/lx-source.js` 在浏览器里运行 KMusic / lx-music 格式的脚本 |
| 自定义脚本 | 手动扩展 | 在「设置 → 音源脚本」粘贴任意 HTTPS `.js` 脚本链接 |

内置音源不只是检索：网易云通过 Meting 跳转到官方 CDN 播放，QQ 音乐通过 vkeys 解析，优先 320K。VIP / 付费歌曲通常拿不到完整直链，此时播放器会按歌名和歌手匹配酷我 320K 继续播放；酷我也没有可用版本时自动跳到下一首。

搜索结果按音源能力分页：网易云和 QQ 每次点「加载更多」追加 20 首，接口返回空页时按钮自动消失；酷我公开接口一次只给 10 首，因此酷我页签没有分页按钮。扩展音源仍是一次性合并所有脚本的结果。

`assets/js/api.js` 负责内置接口：搜索、播放地址解析、歌词获取、音质降级和缓存；`assets/js/lx-source.js` 提供 lx-music 的沙箱环境（`globalThis.lx`、`request`、`on`、`send`、`EVENT_NAMES`），让脚本以为自己在 lx-music 客户端里运行。

搜索页的「扩展音源」会把所有已启用脚本的搜索结果合并展示。脚本的上游接口不稳定时，失败的那一路会被跳过，不影响其他结果；一个脚本都没配置时不会显示这个页签。

`assets/js/store.js` 使用 `localStorage`（键名 `justmusic.v1`）保存收藏、歌单、最近播放和设置。清理浏览器数据会一并清空，换设备也不会同步。

### 关于 KMusic 脚本

`sources/` 下的脚本来自 [Mac-XK/KMusic](https://github.com/Mac-XK/KMusic)，已改成英文文件名以兼容 GitHub Pages：

- `feichangdao.js`：非常刀，聚合网易 / QQ / 酷我 / 咪咕 / 汽水，默认启用
- `suyin.js`：溯音音源
- `luoxue.js`：落雪音源
- `xinlan.js`：新澜音源（需要服务端授权）
- `ikun.js`：ikun 音源

脚本源码同时内联在 `assets/js/lx-bundled.js`，页面不再依赖运行时 `fetch` 读取 `sources/`。这样即使是用 `file://` 直接打开，或者上传时漏掉了 `sources/` 目录，内置脚本也能正常初始化。修改 `sources/` 里的脚本后需要重新生成 `lx-bundled.js`。

这些脚本依赖第三方服务端。服务端是否可用、是否需要授权、什么时候失效，都不由本项目控制。只有「非常刀」和「溯音」声明了搜索能力，其余脚本只负责解析播放地址，不会出现在搜索音源列表里。脚本加载失败不影响内置的酷我音源；可以在「设置 → 音源脚本」里关闭、重新加载，或粘贴新的脚本链接。

> 只添加你信任的脚本。脚本会在当前页面里执行，能够读取页面数据并发起网络请求。

## 音质与兼容性

- 默认 320K。选择无损时，如果歌曲没有 FLAC 版本，会自动回退到 320K，而不是跳过。
- 网易云、QQ 的 VIP / 付费歌曲无法获取完整音频，播放器会自动改用酷我匹配；因此播放条上的实际音源可能和搜索页签不同。
- 网易云和 QQ 的播放直链有时效性。链接过期或 CDN 拒绝时，播放器会先换备用音源，仍失败则自动下一首。
- 公开接口返回的封面和音频有些是 `http://`，代码会统一升级为 `https://`，避免 GitHub Pages 的混合内容拦截。
- 音频能否播放取决于音源返回的直链是否允许跨域访问。个别歌曲可能解析失败，播放器会自动尝试下一首。
- 浏览器通常不允许无交互自动播放。第一次播放需要点击一次播放按钮。
- 本项目没有代理服务器。所有请求都从访客的浏览器直接发出，因此也受对方接口的 CORS 和频率限制影响。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| `Space` | 播放 / 暂停 |
| `←` / `→` | 后退 / 前进 5 秒 |
| `↑` / `↓` | 音量增减 |
| `⌘K` / `Ctrl+K` | 聚焦搜索框 |
| `Esc` | 关闭弹窗 / 队列 / 全屏播放页 |

## 设计

- 深色为默认外观，背景接近纯黑，封面本身提供颜色；浅色主题保留同一套层级。
- 字体使用系统字体栈（SF Pro / PingFang SC / Segoe UI），不加载外部字体，首屏更快。
- 主色是一枚偏暖的红（`#fa2d48`），只用在播放状态、收藏和关键操作上。
- 首页英雄区每天轮换文案与封面；曲库横向滚动，卡片悬停才露出播放按钮。
- 播放条是半透明玻璃层，全屏播放页用封面做模糊背景与光晕。
